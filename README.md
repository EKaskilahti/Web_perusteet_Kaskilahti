# Web_perusteet_Kaskilahti
Web-kehittämisen perusteet harjoitustyö

Ajatuksena on tehdä kahvila.

Index:sisältää perus tietoa kahvilasta, esim. milloin perustettu ja kuka sitä pyörittää.
Menu:tiedostosta löytyy kahvilan tarjottavat ja niiden hinnat. Mahdollisesti myös kuvia eri vaihtoehdoista
Yhteystiedot: Löydät aukioloajat, puhelinnumeron, sähköpostiosoitteen, sijainnin ja mahdollisuuden lähettää palautetta
