# Web_perusteet_Kaskilahti
Web-kehittämisen perusteet harjoitustyö

Ajatuksena on tehdä kahvila.

Index:sisältää perus tietoa kahvilasta, esim. milloin perustettu ja kuka sitä pyörittää.
Menu:tiedostosta löytyy kahvilan tarjottavat ja niiden hinnat. Mahdollisesti myös kuvia eri vaihtoehdoista
Yhteystiedot: Löydät aukioloajat, puhelinnumeron, sähköpostiosoitteen, sijainnin ja mahdollisuuden lähettää palautetta


Valitsin Gridin layout-ratkaisuksi, koska se soveltuu hyvin koko sivun rakenteen toteuttamiseen. Gridin avulla navigaatio ja sisältöalue voidaan sijoittaa selkeästi vierekkäin. Ratkaisu sopii mielestäni parhaiten kavilalle, koska sen avulla sivun tiedot on helposti hahmoteltavissa ja se sopii myös hyvin mobiililaitteelle. Tämä on mielestäni tärkeää, koska harva tarkistaa kahvilan tarjottavat koneella, vaan se hoituu liikkeellä ollessa puhelimella.
